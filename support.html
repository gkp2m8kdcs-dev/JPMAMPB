Before You Write — Quick Checks

  1. Update the app. Most reported issues are resolved in the latest version.
  2. Restart the app. Fully close JPMAMPB from the app switcher and reopen it.
  3. Restart the device. Resolves most transient iOS issues.
  4. Check iOS version. JPMAMPB requires a recent version of iOS.
  5. Review permissions. Camera and photo access can be toggled in iOS Settings → Privacy.

Writing a Helpful Bug Report

The more context you give, the faster we can help. Please include:

  • What you were doing — which screen, which action, what you tapped.
  • What you expected to happen
  • What actually happened — exact text of any error message if shown.
  • Device & iOS version — iPhone model and Settings → General → Software Version.
  • App version — visible on the Settings tab.
  • Screenshots or screen recordings if applicable.

Please do not include brokerage passwords, account numbers, or other sensitive financial credentials. JPMAMPB does not need them to diagnose issues.

Feature Requests

We love hearing what you'd like to see next. Send feature requests to the same support email with the subject line starting with Feature:. Please describe:

  • The problem you're trying to solve
  • Your proposed solution
  • Any alternatives you've considered

We review every request, but cannot guarantee timelines for individual features.
